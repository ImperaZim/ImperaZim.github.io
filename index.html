about

A random person, mostly found in the void.

I'm known as ImperaZim — a programmer who really likes indie games with chaotic and cyberpunk settings. I like to consider myself a random person, more interested in experimenting with technology than following a straight line.

My main project is Amsonia, an independent Minecraft: Bedrock Edition server software derived from PocketMine-MP. Around it, I build tools such as EasyLibrary and Lazuli, while also working on web infrastructure through Kiyari Studios.

I enjoy moving between server internals, package tooling, scripting languages and frontend experiments, usually giving everything a nocturnal glitch aesthetic along the way.

Note: I get quietly fixated on Nazuna, so if the visuals feel extra special, that’s why.
